# Ship catalog attribution

Cargo Run's bundled ship-catalog.json is adapted from the community-maintained
[Star Citizen Wiki Ships table](https://starcitizen.tools/Category:Ships), category
revision 396448, retrieved 2026-11-01. Each entry links to its source article and,
where available, records that article's revision and timestamp.

[Wiki copyright policy](https://starcitizen.tools/Star_Citizen_Wiki:Copyrights).
Adaptations: selected name/manufacturer/Cargo (SCU)/production-state columns,
excluded nonpositive or unknown capacities, omitted prices, images and prose,
added stable local IDs and snapshot metadata. The adapted data is distributed
under CC BY-SA 4.0; application code retains its existing license.

Snapshot coverage: 250 rendered category rows, 126 positive-SCU entries,
105 flight ready and 21 other production states. All roles are eligible.
124 zero/unknown/unsupported-capacity rows are excluded. This is coverage of the
chosen source, not a claim to cover every game entity. Cargo capacity is the
Wiki Cargo capacity (SCU), not personal storage in micro-SCU or a verified
container packing simulation. No single game patch is implied by a Wiki snapshot.
No runtime scraping or remote assets are used.
